# NODAYSIDLE workbench

Approved direction: dark, desktop-first, editor-first. ENERGY 1 / RHYTHM 2 / MOTION 1.

- BrandMark remains the identity anchor; no replacement assets or rebrand.
- Geist supports readable controls; Geist Mono distinguishes editable prompt content.
- Near-black surfaces reduce glare during long editing sessions; the existing indigo accent marks the primary rewrite action and keyboard focus.
- Dark text on the accent fixes the previous button contrast failure; muted text remains readable on all shipped surfaces.
- Adjacent draft/candidate editors support comparison without repeating the draft; expandable notes provide the deliberate rhythm break.
- Compact configuration precedes editing; examples stay optional so the actual draft is the focal point.
- Borders separate editing and configuration regions; only native modal dialogs use shadow to indicate elevation.
- Motion is limited to interaction states, respecting reduced-motion preferences. No decorative animation or fake loading metrics.
- Native dialogs provide modal focus, Escape handling and restoration; all actions retain 44px minimum targets.
